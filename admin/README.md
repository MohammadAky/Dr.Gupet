# پنل مدیریت دکتر گوپت

اپ مستقل React/RTL برای API ادمین. از ریشهٔ پروژه:

```powershell
cd admin
npm.cmd ci
npm.cmd run dev
```

نشانی محلی پنل `http://127.0.0.1:5174/` است. برای ورود، بک‌اند و سرویس OTP باید اجرا شوند؛ تنها حسابی که بک‌اند از `GET /admin/me` با نقش `ADMIN` تأیید کند به پنل دسترسی دارد. مسیر نمونه و دادهٔ ساختگی وجود ندارد. توکن‌ها در حافظهٔ تب نگهداری می‌شوند و با بارگذاری مجدد باید دوباره وارد شوید؛ درخواست‌های API بدون کوکی ارسال می‌شوند.

کلید دایره‌ای ماه/خورشید در ورود و داشبورد حالت روشن/تاریک را تغییر می‌دهد. نمای کلی فروش بازه‌های امروز، ۷، ۱۴ و ۳۰ روز اخیر دارد. در حالت واقعی، هر بازه از `GET /admin/reports/sales?from=…&to=…&tz=Asia%2FTehran` خوانده می‌شود؛ سایر شاخص‌های وضعیت (موجودی، کاربران و سفارش‌های در انتظار) همچنان تصویر فعلی داشبورد هستند و با انتخاب بازه تغییر نمی‌کنند.

بخش «محصولات» فهرست، درج، ویرایش و حذف محصول، واریانت، تصویر، برچسب و داده‌های مرجع را دارد. فرم درج، اطلاعات پایه و نخستین واریانت (SKU، وزن، قیمت و موجودی) را می‌گیرد و تصویر و برچسب‌ها را نیز در صورت انتخاب ثبت می‌کند. محصول پایه ابتدا غیرفعال ساخته می‌شود و فقط پس از موفقیت مرحله‌های بعد منتشر می‌شود. اگر مرحله‌ای شکست بخورد، شناسهٔ محصول نیمه‌تمام نمایش داده می‌شود تا مدیر آن را در جزئیات تکمیل کند.

بخش‌های سفارش، کاربر، کوپن، دارو و مراکز، پرداخت، گزارش و CSV، لاگ و تنظیمات به مسیرهای API مدیریت وصل شده‌اند. تطبیق دوبارهٔ پرداخت به دلیل خطر تغییر وضعیت سفارش لغوشده تا رفع مورد `.issue/02` غیرفعال است. وضعیت کشیک داروخانه نیز تا تکمیل قرارداد `.issue/08` در پنل قابل ویرایش نیست. API زنده در این بررسی در دسترس نبود؛ مسیرهای شبکه با پاسخ کنترل‌شده آزموده شدند و عملیات واقعی هنوز تأیید نشده است.

در توسعه، Vite درخواست‌های `/api` را به `http://127.0.0.1:3000` می‌فرستد. در استقرار، همین مسیر باید به API بک‌اند پروکسی شود یا `VITE_API_BASE_URL` به نشانی مجاز تغییر کند. توکن و کلید مخفی را در متغیر `VITE_*` نگذارید.

وضعیت و معیار پذیرش فازها در [`README.md`](../README.md) ریشه، بخش ۸، است. برای استفادهٔ واقعی، بک‌اند، درگاه پرداخت و OTP باید راه‌اندازی و آزمون شوند.

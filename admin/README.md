# پنل مدیریت دکتر گوپت — فاز A0

اپ مستقل React/RTL برای API ادمین. از ریشهٔ پروژه:

```powershell
cd admin
npm.cmd ci
npm.cmd run dev
```

پیش‌نمایش طراحی بدون بک‌اند: `http://127.0.0.1:5174/?demo=1`. داده‌ها صریحاً نمایشی‌اند و هیچ عملیات واقعی انجام نمی‌شود. برای ورود واقعی، بک‌اند و سرویس OTP را اجرا کنید؛ تنها حسابی که بک‌اند با نقش `ADMIN` تأیید کند به داشبورد دسترسی دارد. دسترسی در حافظهٔ تب نگهداری می‌شود و با بارگذاری مجدد باید دوباره وارد شوید.

کلید دایره‌ای ماه/خورشید در ورود و داشبورد حالت روشن/تاریک را تغییر می‌دهد. نمای کلی فروش بازه‌های امروز، ۷، ۱۴ و ۳۰ روز اخیر دارد. در حالت واقعی، هر بازه از `GET /admin/reports/sales?from=…&to=…` خوانده می‌شود؛ سایر شاخص‌های وضعیت (موجودی، کاربران و سفارش‌های در انتظار) همچنان تصویر فعلی داشبورد هستند و با انتخاب بازه تغییر نمی‌کنند. نمودار روزانهٔ بک‌اند برحسب UTC است؛ برای تطبیق دقیق با روز محلی به قرارداد بک‌اند نیاز است.

در توسعه، Vite درخواست‌های `/api` را به `http://127.0.0.1:3000` می‌فرستد. در استقرار، همین مسیر باید به API بک‌اند پروکسی شود یا `VITE_API_BASE_URL` به نشانی مجاز تغییر کند. توکن و کلید مخفی را در متغیر `VITE_*` نگذارید.

فازهای بعدی در [`README.md`](../README.md) ریشه، بخش ۸، هستند. A0 شامل شِل، ورود و داشبورد است؛ عملیات مدیریتی و گزارش‌ها هنوز UI ندارند.

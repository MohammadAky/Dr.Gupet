## اثر

## معیار رفع و پذیرش مالک بک‌اند

- bootstrap مرجع‌ها و ادمین از seed نمایشی جدا شود؛ دادهٔ نمایشی فقط در حالت آزمایشی صریح و محیط ایزوله مجاز باشد.
- ارتباط دارو/نوع پت از قرارداد Prisma یا SQL معتبر MySQL استفاده کند؛ مسیرهای seed تکرارپذیر و فاقد ایجاد نمونهٔ تکراری باشند.
- خطای مرحلهٔ ضروری bootstrap موجب خروج ناموفق شود؛ وضعیت مدیر و دادهٔ مرجع پیش از پیام موفق بررسی شود.
- روی MySQL خالی ایزوله دو بار اجرا، تعداد رکوردها و عدم ایجاد محصولات/دارو/کوپن نمایشی در حالت production بررسی شود؛ backup پیش از هر اجرای روی دادهٔ موجود لازم است. seed موجود برای ورود محصولات واقعی اجرا نشود.

**وضعیت:** باز؛ یافتهٔ کد و قرارداد SQL، بدون تغییر بک‌اند یا اجرای seed روی سرور.

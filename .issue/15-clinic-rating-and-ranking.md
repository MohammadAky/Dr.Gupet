# ذخیرهٔ امتیاز و ترتیب مراکز برگرفته از Google

**نوع:** نیاز قرارداد بک‌اند برای فهرست واقعی کلینیک‌ها  
**وضعیت:** باز؛ قرارداد در کد `0160b12` و API آزمایشی فعال بررسی شده است

## شواهد و نیاز مالک

مالک خواسته ۱۰ کلینیک مشهد براساس امتیازی که در Google نمایش داده می‌شود انتخاب و اولویت‌بندی شوند؛ تأیید مستقل کیفیت درمان لازم نیست. مدل Clinic در `backend/prisma/schema.prisma` و پاسخ‌های عمومی/فرم مدیریت فعلی فیلد امتیاز، تعداد نظر، URL منبع یا اولویت نمایش ندارند. در `backend/src/modules/clinics/clinics.service.ts` ترتیب عمومی `isVerified desc`, `is24h desc`, `name asc` است؛ ترتیب ورود داده یا مرتب‌سازی یک صفحه در فرانت، رتبه‌بندی پایدارِ کل فهرست را تضمین نمی‌کند.

## درخواست اجرایی

1. قرارداد ثبت/ویرایش و پاسخ عمومی برای امتیاز اختیاری Google (۰ تا ۵)، تعداد نظر صحیح غیرمنفی، تاریخ مشاهده و URL منبع معتبر تعریف شود. مقدار نامعلوم null باشد؛ صفر یا امتیاز ساختگی جای آن قرار نگیرد. فیلدها در مدیریت قابل ویرایش باشند؛ دادهٔ استخراج‌شده فقط از نشست ADMIN ثبت شود.
2. گزینهٔ مرتب‌سازی سرور بر اساس امتیاز نزولی، تعداد نظر نزولی در تساوی و ID ثابت برای تساوی کامل، با null در انتها و صفحه‌بندی صحیح اضافه شود. مستندات قرارداد به‌روز شود.
3. `isVerified` تأیید مرکز توسط اپراتور است و با داشتن امتیاز Google برابر نیست؛ هنگام ورود این داده خودکار true نشود. نمایش امتیاز باید منبع و تاریخ مشاهده داشته باشد و مالکیت/تأیید Google یا تضمین کیفیت درمان القا نکند.
4. URLهای منبع فقط با طرح امن و دامنهٔ مجاز ذخیره/ارائه شوند؛ هر واردسازی آینده نباید URL دلخواه را بدون کنترل شبکه در سرور fetch کند. لازم نیست برای این نیاز سرویس اسکرپینگ در ریپو اضافه شود.

## معیار پذیرش

- اعتبارسنجی امتیاز، تعداد نظر، تاریخ و URL؛ عدم ویرایش عمومی؛ ثبت audit تغییر ادمین آزموده شود.
- چند صفحه از مراکز با امتیازهای مساوی/نامعلوم بدون تکرار یا حذف مرتب شوند؛ فیلتر شهر و استان محفوظ بماند.
- فرانت پس از نهایی‌شدن قرارداد به ترتیب API متصل شود؛ امتیازهای تاریخی صرفاً با برچسب منبع نمایش یابند.

داده و ابزار تحقیق بنا به خواست مالک خارج مخزن نگهداری می‌شوند؛ این پرونده دادهٔ کلینیک یا کد بک‌اند اضافه نمی‌کند.

## بررسی محیط آزمایشی — ۲۰۲۶-۱۰-۰۴

ده مرکز منتخب، با اطلاعات Google مشاهده‌شده در ۲۰۲۶-۱۰-۰۳، تحت مجوز یک‌بارهٔ مالک در SQLite مستقل وارد شدند. هر ۱۰ جزئیات عمومی و ماندگاری پس از restart بررسی شدند؛ `isVerified=false` حفظ شد. فیلدهای امتیاز/تعداد نظر/منبع همچنان وجود ندارند و ترتیب واقعی API با رتبه‌بندی Google متفاوت است؛ این پرونده با ورود داده بسته نمی‌شود. هیچ داده یا ابزار استخراج در مخزن اضافه نشده است.

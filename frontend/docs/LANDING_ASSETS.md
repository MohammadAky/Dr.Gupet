# دارایی‌های لندینگ — ۱۳ اکتبر ۲۰۲۶

این تصویرها با ابزار داخلی OpenAI image generation ساخته شده‌اند. تصویرسازی‌های خیالی و نمونهٔ طراحی هستند؛ عکس مشتری، مرکز واقعی یا کالای ثبت‌شده نیستند. نوشته و دکمه داخل HTML فارسی/RTL رندر می‌شوند و جزئی از پیکسل تصویر نیستند. فایل‌های اصلی خارج از Git حفظ و WebPها با حفظ نسبت و کیفیت ۸۴ در public/brand صادر شده‌اند. هیچ تصویرِ سایت مرجع، فونت خارجی یا tracker اضافه نشده است.

| فایل‌های داخل public/brand | خروجی / کاربرد |

| landing-family-{640,1600}.webp | بنر اول: زن جوان بزرگسال، سگ، گربه و پرنده در یک صحنه |
| landing-meal-{640,1600}.webp | بنر دوم: بستهٔ غذای نمونه؛ محصول واقعی نیست |
| landing-treat-{640,1600}.webp | بنر سوم: بستهٔ تشویقی نمونه |
| landing-{family,meal,treat}-mobile.webp | نسخهٔ عمودی ۷۲۰×۹۰۰ همان صحنه‌ها برای قاب موبایل |
| species-{dog,cat,bird}.webp | پرتره‌های مربع ۳۲۰×۳۲۰؛ نمایش در دایرهٔ دسته‌بندی |

دارایی‌های قبلی discovery-pharmacy، discovery-medicine و clinic-care برای کارت‌های نمونه استفاده می‌شوند؛ provenance و prompt آن‌ها در DESIGN_SYSTEM ثبت شده است. تمام کارت‌ها و قیمت‌های نمونه با برچسب «نمونهٔ طراحی» مشخص‌اند. تصویر hero-companions قبلی در این لندینگ استفاده نمی‌شود و فایل آن حفظ شده است.

Recompose the existing complete subject group into the center of the portrait frame, with ALL faces, animal ears/bird crest and package outline clearly visible comfortably inside the central 80 percent width and height. Do not crop off faces or stretch/deform anatomy. The website renders its headings outside this mobile artwork. Opaque background.

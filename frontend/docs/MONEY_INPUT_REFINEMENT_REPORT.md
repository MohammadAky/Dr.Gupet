# ورودی تومان — بازبینی محلی ۱۳ اکتبر ۲۰۲۶

قیمت هنگام تایپ با ارقام فارسی و جداکنندهٔ سه‌رقمی نمایش داده می‌شود؛ مثلاً `123456` به «۱۲۳٬۴۵۶» تبدیل می‌شود. مقدار ارسالی به API همان عدد صحیح تومان است؛ صفر اضافه، تبدیل ریال، گردکردن یا تغییر واحد وجود ندارد. مالک در ۱۴ اکتبر انتشار را تأیید کرد؛ تغییر برنامه در `d36b00d76436ba00f0f14c4c07645fc05d48f42c` به GitHub و VPS رفت و هر سه build همان revision را تأیید کردند. به‌روزرسانی‌های بعدیِ صرفاً گزارش، رفتار برنامه را تغییر نمی‌دهند.

## دامنهٔ اصلاح

۱۳ مقدار پولی: پنج فیلد قیمت/قیمت مقایسه‌ای کاتالوگ، سه فیلد مبلغ تخفیف ثابت/حداقل سفارش/سقف تخفیف، دو تنظیم هزینهٔ ارسال، قیمت اختیاری پیش‌نویس بخش لندینگ و دو فیلتر قیمت مشتری. درصد تخفیف، تعداد موجودی، وزن، کد OTP و مدت انقضا تغییر نکرده‌اند.

کامپوننت کوچک هر SPA در ساختار موجود قرار دارد؛ وابستگی، معماری مشترک یا قرارداد شبکهٔ تازه اضافه نشده است. جای نشانگر، انتخاب بازه، حذف، paste، IME و مقدار کنترل‌شده بررسی شده‌اند. ورودی نامعتبر مانند اعشار، علامت و نمای علمی به مبلغ دیگری تبدیل نمی‌شود و باید از اعتبارسنجی موجود عبور کند.

## شواهد و محدودیت

- gate کامل فرانت‌اند: **۵۹ فایل، ۴۲۵ تست**؛ lint، TypeScript و build تولیدی پاس شدند.
- gate کامل ادمین: **۱۹ فایل، ۱۱۸ تست**؛ lint، TypeScript و build تولیدی پاس شدند. آزمون قرارداد درخواست‌ها مقدار خام تومان را بررسی می‌کند؛ این آزمون‌های ایزوله، ذخیرهٔ واقعی در دیتابیس نیستند.
- آزمون مرورگر تولیدی محلی: تایپ پیاپی `123456` و `300000` به «۱۲۳٬۴۵۶» و «۳۰۰٬۰۰۰» رسید؛ اعمال فیلتر URL با `minPrice=123456&maxPrice=300000` ساخت و از API واقعی پنج محصول دریافت کرد. هیچ رکوردی ذخیره یا تغییر نکرد.
- ادامهٔ ۱۴ اکتبر: ورود با اطلاعات قدیمی فایل خصوصی HTTP 401 گرفت؛ پس از به‌روزرسانی فایل توسط مالک، همان پیش‌نمایش با حساب معتبر HTTP 200 و دسترسی واقعی ADMIN داشت. تایپ پیاپی `1234567` در قیمت پیش‌نویس محصول به «۱٬۲۳۴٬۵۶۷» رسید و caret در انتهای مقدار حفظ شد؛ پیش‌نویس بدون ذخیره کنار گذاشته شد. هیچ رکورد محصولی برای این آزمون ساخته یا تغییر نکرد. proxy محلی ادمین هم با فرانت‌اند یکسان شده است؛ مشکل قبلی، رگرسیون قیمت یا CORS اثبات‌شده نبود.

این مرحله بک‌اند را تغییر نداده است. نتیجهٔ تاریخی بک‌اند **۴۵ suite / ۴۳۴ تست** از انتشار قبلی است و برای این تغییر دوباره اجرا نشده است.

پس از انتشار، ورود واقعی `admin.drgupet.ir` با حساب موجود موفق شد؛ قیمت پیش‌نویس «۱٬۲۳۴٬۵۶۷» و caret انتهایی دوباره بررسی و پیش‌نویس بدون ذخیره کنار گذاشته شد. این پذیرش نقش ADMIN است؛ حساب مستقل USER، پیامک و خرید واقعی با این آزمون اثبات نمی‌شوند.
